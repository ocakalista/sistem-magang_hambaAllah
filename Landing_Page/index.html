Akses Khusus 4 Aktor Utama

Sistem terdistribusi secara transparan untuk memenuhi seluruh kebutuhan operasional magang kampus.

🎓

Mahasiswa

Eksplorasi lowongan mitra valid, ajukan lamaran online, pantau status seleksi, dan isi logbook mingguan.

👨‍🏫

Dosen

Memonitor aktivitas logbook harian/mingguan mahasiswa bimbingan secara daring tanpa perlu berkas fisik.

🏢

Mitra Perusahaan

Membuka lowongan baru, mengelola profile instansi, serta menyeleksi dan memberikan nilai akhir magang pelamar.

⚙️

Admin

Mengelola database pengguna, memvalidasi berkas pendaftaran mitra baru, serta mengonfigurasi kuota dan sistem.

Langkah Mudah Instalasi APK

Ikuti langkah berikut agar aplikasi terpasang sempurna karena file diunduh di luar Google Play Store.

1

Unduh Berkas

Klik tombol "Unduh Aplikasi" di atas, Anda akan diarahkan ke link file `.apk` di Google Drive.

2

Buka Unduhan

Buka aplikasi File Manager di HP Anda, cari folder Download dan klik file APK yang diunduh.

3

Izin Android

Bila muncul proteksi keamanan, pilih Pengaturan lalu aktifkan "Izinkan dari sumber ini".

4

Pasang Aplikasi

Klik kembali Install/Pasang pada file. Tunggu sejenak dan aplikasi siap digunakan login.

⚠️
