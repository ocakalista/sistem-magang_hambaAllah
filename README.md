# HambaAllah_Project

## 📌 Deskripsi Project
HambaAllah_Project merupakan aplikasi Sistem Pendaftaran Magang berbasis mobile yang dikembangkan menggunakan Flutter dengan implementasi arsitektur Client-Server berbasis RESTful API. Sistem ini dirancang untuk membantu proses pendaftaran magang secara digital mulai dari registrasi pengguna, pengelolaan lowongan magang, hingga monitoring aktivitas logbook mahasiswa.

## 🚀 Features
- Login & Registrasi Pengguna
- Dashboard Lowongan Magang
- Detail Informasi Lowongan
- Pendaftaran Magang
- Input Logbook Mingguan
- Monitoring Status Pendaftaran
- Manajemen Data Pengguna
- Sistem Validasi Kuota Magang

---

## 🏗 System Architecture

| Komponen | Teknologi | Deskripsi |
|---|---|---|
| Frontend | Flutter (Dart) | Menampilkan antarmuka aplikasi mobile Android/iOS |
| Backend | Laravel (PHP) | Menyediakan RESTful API dan logika bisnis sistem |
| Database | MySQL | Menyimpan data pengguna, lowongan, dan logbook |
| Authentication | JWT / Laravel Sanctum | Keamanan autentikasi pengguna |
| Communication Protocol | HTTPS | Komunikasi data client-server |
